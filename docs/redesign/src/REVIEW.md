観点：
1. **情報の欠落**：現行ページ（実装と本番）にある情報・件数・リンク・表の列が、見本にすべてあるか。無いものを列挙。数値・名前が実データと合っているか（元データと突き合わせる）。
2. **崩れ**：横はみ出し、文字の切れ・重なり、折り返しの不揃い、横並びの上下端の不一致、タップ領域40px未満、幅の境目での急な崩れ、JSエラー、操作時の崩れ。
3. **RULES.md の違反**：色の面に白以外の文字、淡い地に同系色の文字、色つきアクセント線、余白のばらつき、カードの中のカード、スカスカ、何でもカード、のっぺり、など。
4. **その端末での作りとして正しいか**：スマホは1件1行・板1枚・親指で操作しやすいか、最初の画面で何が見えるか。PCは表にすべきものが表か、横幅を使えているか、間延びしていないか。タブレットがPCの部品を積んだだけになっていないか。
5. **見やすさ・使いやすさ**：そのページの目的（調べる／比べる／読む／探す）を最短で果たせるか。図は一目で読めるか。もっと良い見せ方があれば具体的に。
6. **トップとの統一感**：同じサイトに見えるか。食い違う部品があれば具体的に。
