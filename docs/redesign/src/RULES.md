# 競馬データ.com リデザイン v6 見本のルール

2026-11-18〜19 にオーナー（久保田さん）とトップページで詰めた方向性。ほかのページの見本もこれに従う。
確定した見本：`docs/redesign/v6-looks.html`（トップ）。生成元：`docs/redesign/src/pages/top.mjs`。

## 最優先
- **ユーザーが見やすいか、使いやすいかが全て。** 既存デザインにこだわらずゼロベースで考えてよい。
- **コンテンツ（載せる情報・件数・リンク）は現行ページから削らない。** 予想に使う人向けでデータの網羅性が最優先。
  ランキングは10件＋「さらに表示」で最大50件、表は全項目、最大値ハイライト、内部リンクなど、現行の仕様は踏襲する。
- 極端に振らない。オーナーは「カードを全部やめる」「全部カードにする」のどちらも却下した。中間を取る。
- オーナーが嫌うもの：「AIっぽい」「素人っぽい」「チープ」に見えるもの。
  - 淡い色地に同系色の文字（淡い緑地＋緑文字のバッジなど）。**色の面には白い文字だけ**を載せる。
  - 板の上端や左端の色つきアクセント線、ゼロ埋め番号、↗アイコン、グラデーション、装飾目的の絵文字。
  - くすんだ配色。はっきりメリハリのある色にする。
  - 単色の地に単色のカードが並ぶだけの、のっぺりした画面。大きさ・太さ・絵で強弱を付ける。
  - 何でもカードにすること。表の方が見やすいものは表にする。「カードの中にたくさんカード」も不可。
  - 余白が大きくスカスカなこと。詰めれば1行に収まるものを改行して余白を作らない。要素は幅いっぱいに大きく使う。
  - 横に並べた要素の上端・下端が揃っていないこと、余白が場所ごとにばらつくこと。

## 形
- 角丸：板は 700px以上 16px・スマホ 12px（`--r-panel`）、絵 12px、マス 8px、丸ボタン 9999px。影は板に薄く1種類。
- 余白：PC は節の間 40px・板と板 16px・本体の左右 24px。スマホは節の間 28〜32px・板と板 12〜16px・マスの間 6〜8px。
- 見出し：節の見出しは地の上（PC 24px / スマホ 20px・太字）。板の見出しは板の中（18px / 15〜16px・太字）。
- 数値は `.num`（Roboto、等幅数字）。
- 横に並ぶ要素は上端・下端を必ず揃える。高さが違う中身は、短い方を伸ばす／行を固定高さにする／表1枚にまとめる、で揃える。
- 馬場の札（芝・ダート・障害）は、右に並ぶ距離の行数に合わせて縦に伸ばす。
- 動き：棒は画面に入ったら左から伸びる、数値は数え上がる、カードは順に浮き上がる。1回だけ。`prefers-reduced-motion` では止める。
  「動きがあり、ビジュアライズが見やすい」はサイトの差別化要素として持っておきたい（オーナー）。

## PC（1100px以上）
- 左にメニュー（240px、白、画面左端まで塗る）、本体は最大1440px、幅1800px以上で右に広告とAI案内の列（300px）。枠は `lib.mjs` の `page()` が出す。
- ヘッダーはメニューボタンとロゴだけ。検索やAI予測ボタンは置かない。
- 絵（コラム）は板に入れず地に置く。データは白い板の中。
- 表にできるものは表にする（例：今週開催は「競馬場｜芝・ダート・障害の行｜距離のマス」）。

## スマホ（700px未満）
- 灰の地に「1セクション（または1つのまとまり）＝白い板1枚」。板の中に板は置かない。
- 一覧は1件＝1行（例：リーディングは 順位・名前・棒・勝利数 を1行42px）。
- 距離・名前は淡いマス（高さ34〜36px、同じ幅の列）。距離は「1200m」と m まで書く。1行4個。
- 五十音はアコーディオン（1行＝1つの行、開くと名前のマス3列）。
- AI予測のカードは中身ぴったりの幅で横に送る。カードの中に空きを作らない。
- 固定するのはヘッダー（52px）と下部メニューだけ。

## 作り方
- 各ページは `docs/redesign/src/pages/<名前>.mjs` を作り、`import * as L from '../lib.mjs'` して `L.page({ title, body, current, out, css, js })` を呼ぶ。
  - `out` は `docs/redesign/` 直下のファイル名（`v6-<名前>.html`）。ブラウザ確認用が `docs/redesign/src/.preview/<同名>` に出る。
  - ページ固有のCSSは `docs/redesign/src/css/<名前>.css` に書き、`css: fs.readFileSync(...)` で渡す。固有のJSも同様。
  - **`lib.mjs`・`top.css`・`themes.css`・`top.js`・`pages/top.mjs` は編集しない**（全ページ共通。複数の作業者が同時に触ると壊れる）。足りない部品は自分のページのCSS／JSに書く。
- 使える共通部品（`lib.mjs`）：`head(title, sub, more)`（節の見出し）、`dists(rc)`（競馬場の距離の表）、`rank(rows, unit)`、`kana(...)`、`ad`（広告枠）、`I`（アイコン）、`esc`、`VENUES`、`SURF`、`of(rc, sf)`、`dl(c)` など。CSSクラスは `top.css`→`themes.css` の順に後勝ちで効く（追記を重ねているので、同じセレクタは後ろが有効）。
- 数値・名前は必ず本番の実データを使う（`lib/get*DataFromGCS.ts` にあるURLから取得、`public/data/`、`lib/*.ts`）。作り物の数字は入れない。取得したJSONは `docs/redesign/src/data/` に保存する。
- 見本のリンクは `href="#" data-inert`（押しても動かない）でよい。
