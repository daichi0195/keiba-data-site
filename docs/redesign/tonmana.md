# 競馬データ.com トンマナルール v2.1

GPT v2 をベースに、Claude レビューで以下を修正した版。
- 得意バッジ（#EAF7EF）と芝バッジ（#E2F7EB）がほぼ同色 → 得意/苦手は「白地＋黒文字＋色付きの枠」のチップに変更（矢印は良し悪しが直感的に分からない、地や文字まで色を付けるとAIっぽくなる、というオーナー判断）。芝バッジ（枠なし・小）とは形で分ける
- 使われなくなった --brand-hover / --brand-pressed / --on-brand を削除
- セクションナビの選択表現を「#222塗りチップ」に一本化
- メーターは今のサイトと同じ横型。マーカーが左から判定位置へスライド（rotate ではなく translateX）
- ブランド緑の棒は白地で 2.61:1 のため、棒には必ず数値ラベルを添える（色だけで値を伝えない）
- --data-1/2 は淡すぎて棒には使えない → ヒートマップ背景専用

## 0. サイト前提
- 競馬統計データサイト。コース・種牡馬・騎手・調教師の成績。スマホ流入約7割
- 閲覧行動：検索流入 → 傾向を把握 → 数値を比較 → 詳細表 → 関連ページ
- 参考は Airbnb。白い面・柔らかい角丸・余白で区切る。写真の代わりにグラフの緑で彩りと動きを出す

## 1. デザイン原則
1. 結論から見せる：結論 → 主要数値 → グラフ → 詳細表
2. 色の役割を分ける：ブランド緑＝ブランド/グラフ系列、#222＝操作の主役、芝ダート＝馬場属性、色付きの枠＝得意/苦手
3. 面と余白で区切る：#F7F7F7 の背景に白カード。カードに影・枠なし（左右のサイドバーのカードも同じ）
   - 背景は body の #F7F7F7 と、ゆっくり動く蹄鉄パターン（globals.css の body::before、動きを減らす設定では停止）。全ページ共通で、`.canvas` 自体は透明にして背景を透かす（オーナー指定）
4. スマホで比較できる：短い集計表とランキングは別部品。全指標へのアクセスは残す
5. 数字を読みやすく：等幅数字・右揃え・単位と桁を統一
6. 動きには意味を：グラフの伸長・状態変化だけ。1回だけ再生
7. タップ領域44px以上
8. 中身を切り替えない：タブや指標切替で表示内容を入れ替えない。騎手・種牡馬・母父・調教師などは独立したカードで並べる。開閉（全項目を見る・さらに表示・Q&A）はよい
9. 縦に長くしない：グラフは「ラベル｜横棒｜数値」の1行1段（高さ32px）。長い表は折りたたむ

## 4. 余白・角丸・影
- 4px基準：4 / 8 / 12 / 16 / 24 / 32 / 40 / 48
- ページ左右 SP16 / PC24、最大幅1120、長文720
- セクション間 SP32 / PC48、カード内 SP16 / PC24、カード間16
- 角丸：カード16、内部要素・ボタン・入力12、チップ・バッジ9999
- 影は固定ヘッダー・浮遊要素だけ：0 4px 16px #00000012, 0 0 0 1px #00000008

## 5. コンポーネント
- **KPIタイル**：ラベル13 → 数値28 → 補足13。SP2列。母数か比較基準を補足に入れる
- **傾向メーター**：指標名 → 判定ラベル（太字）→ 3〜5段階の横型トラック → 根拠の数値。マーカーは #222
- **短い集計表**（人気・枠順・脚質・性別・馬体重）：複勝率の横棒（1行1段）が標準。枠順も枠番バッジを左に置いた横棒。全14列は「全項目を見る」で横スクロール表
- **ランキング**（騎手・種牡馬・母父・調教師）：それぞれ独立したカードに全13項目の表。件数は既存仕様どおり初期10件→「さらに表示（残り40件）」で最大50件。順位と名前の列を固定し、横スクロールすると名前の列が先頭3文字に縮む。並び替えの切替は置かない
- **広告枠**：デザイン案には置かない
- **同じ競馬場の他コース**：横スクロールにしない。1枚のカードに馬場ごとの行（左に芝/ダートのバッジ、右に距離チップを折り返し）。表示中のコースはナビと同じ選択色
- **コースページ冒頭**：背景色や線画などの装飾は付けない。パンくず→バッジ→タイトル→リード→メタ情報→結論カード（判定3つ）の順にキャンバス上に置く
- **荒れやすさ**：5段階（堅い／やや堅い／標準／やや荒れ／荒れやすい）
- **表の共通仕様（現行踏襲）**：角丸なし、外枠は最下段の下まで1pxで囲む。ランキングの順位1〜3位は色付きの角丸で囲む（1位 #FCEA7F／2位 #CBDEFF／3位 #EFC79F、文字 #333・600、高さ20px・角丸4px）
- **判定の根拠の数値**（コースの特徴カード内）：ラベルは左、数値は右寄せ
- **データ表**：ヘッダー12 / 本文13、横罫線のみ、1列目固定（幅は中身に合わせる）、行の高さは条件別40px・ランキング36px（予想用に一度に見える行数を優先。オーナー承認済み）。右端に次の列を少し見せてスクロールできることを示す。固定列は不透明な背景＋右に1pxの区切り線。スクロール領域に左右の余白や角丸のセルを作らず、角丸は外枠に付ける（固定列の左に後ろの列が透けないように）
- **チップ**：見た目36px、タップ領域44px（::after で上下に広げる）、文字14。非選択＝白＋--line枠、選択＝#222＋白
- **得意/苦手チップ**：白地＋--ink 文字（500）＋1.5px の枠。得意＝--good-line、苦手＝--bad-line。色を付けるのは枠だけ
- **バッジ**：高さ24、12px、完全な丸。芝・ダート・枠番・注意。操作できない要素
- **ボタン**：主要＝#222＋白（高さ48・角丸12）、副次＝白＋--line枠、テキスト＝--link＋下線。フォーカスは2px --focus-ring＋2pxオフセット
- **ヘッダー**：白56px、スクロール時のみ影
- **セクションナビ**：スマホのみ。ヘッダー直下に固定、横スクロールのチップ列（PCは右の目次があるので出さない）。選択中はテーマカラー #1DB854 塗り＋白の太字（オーナー指定「ナビゲーションボタンのアクティブはテーマカラー」。#1DB854×白はコントラスト2.61:1のため、ナビの選択表現＝スマホのセクションナビ・PCの目次・コラムの並び替えチップに限る。ページ送りなどそれ以外の選択は #222＋白）
- **メタ情報**：詳細ページ冒頭に集計期間・母数・最終更新日を常設

## 6. やらないこと
- グラデーション、装飾目的の絵文字、ページごとの背景模様（全ページ共通の蹄鉄パターンは例外）
- 緑を「良い結果」の意味で使う。芝の緑とブランド緑を混同させる
- 色だけで意味を伝える
- カードの入れ子、常時の強い影、全セルの格子罫線
- 母数の少ない結果を根拠なく強調する
- ループするアニメーション、表内のカウントアップ

## 7. グラフ
- 共通：基本系列 --data-4、注目 --data-5＋太字の数値、トラック --chart-track（#E9E9E9）、グリッド #E9E9E9、軸ラベル #6A6A6A。棒・点には必ず数値ラベル
- 横棒：成績比較の標準。0起点、同じ比較内で最大値を揃える。棒の高さ12px、角丸9999
- メーター：荒れやすさ・枠順傾向・脚質傾向。閾値は指標ごとに固定
- 折れ線（Chart.js）：成長曲線・リーディング推移。線幅3px、複数系列は線種とマーカーも変える。Y軸が0起点でないときは目盛りで明示
- 季節別の棒：春→夏→秋→冬、0起点、棒の上に数値
- 芝ダート比較：--turf-solid / --dirt-solid、凡例に「芝」「ダート」
- ツールチップ：#222地＋白文字。タップで表示、外側タップかEscで閉じる。Canvasのグラフには要約文か代替の表を付ける

## 8. モーション
| 対象 | 時間 | 動き |
|---|---|---|
| 横棒 | 650ms | 左端から伸びる（scaleX）。行ごとに40msずつ遅らせる |
| メーター | 700ms | マーカーが左端から判定位置へスライド（translateX） |
| カウントアップ | 650ms | KPI数値だけ。表内では使わない |
| アコーディオン | 220ms | 高さとフェード |
| ページ内ジャンプ | 360ms | 固定ヘッダー＋ナビ分をずらして停止 |
- グラフ系は画面に20%入ったら1回だけ再生
- イージング：グラフ cubic-bezier(.22,1,.36,1)、UI cubic-bezier(.2,0,0,1)
- prefers-reduced-motion では全て0msで完成状態を表示。Chart.js は animation:false
- アニメーション前でも数値ラベルは最初から読める状態にする

## コラムのサムネイル

競馬サイトらしい引きを優先し、YouTubeサムネイル風にする（オーナー判断。サイト本体のシンプルさとは分けて考える）。ChatGPT の画像生成で、記事ごとにスレッドを分けて作る。以下の共通指定の末尾に【この記事】の行を足して送る。保存は `public/images/articles/<番号>.jpg`（1672×941、JPEG品質85）。

> 競馬データサイト「競馬データ.com」のコラム記事用サムネイルを1枚作成してください。横長16:9。YouTubeのサムネイルのように、一覧で並んだときにパッと目を引く迫力のあるデザインにしてください。ただし安っぽくならず、洗練された仕上がりに。【スタイル】躍動感のある高品質なデジタルイラスト。背景は明るい競馬場（スタンドと芝コース）を少しぼかして奥行きを出し、スピード感を出す。色はブランドのグリーン#1DB854を基調に、アクセントに黄色#FFD43B。【文字】日本語タイトルを画面の左側約45%に収まる大きさで、極太のゴシック体で配置（大きすぎないこと）。白文字に濃い緑の太い縁取りと軽い影をつけ、背景の上でもはっきり読めるように。キーワードは黄色の文字（濃い緑の縁取り）で一番大きく。左上に小さな帯ラベル「データで検証」（緑地に白文字）。左側の文字の背景に緑の筆で払ったような帯を控えめに。【イラスト】右半分にテーマを象徴する馬と騎手を大きく、迫力ある構図で（勝負服は緑）。【制約】指定した文言以外の文字・数字・ロゴは入れない。誤字なし。文字が画像の端で切れないように。
>
> 【この記事】大きい文字：「…」、その下の文字：「…」。イラスト：…

- 大きい文字＝記事のキーワード（2〜6字）、下の文字＝問いかけ（〜8字）。誤字は必ず目視で確認する
