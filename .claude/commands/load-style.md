トンマナ学習（`/generate-article` のSTEP 2相当）の確認だけを単体で実行してください。

## 手順

1. `[STEP 2] トンマナ学習を開始します` と1行ログ出力
2. Glob で `content/articles/**/*.{mdx,md,html,txt}` を一覧取得
3. 更新日時が新しい順に**最大10件**まで選び、それぞれを Read で読み込む（各ファイル冒頭3000字まで内部保持）
4. 読み込み結果をユーザーに以下の形式で表示:
   - 読み込んだファイル名と文字数のリスト
   - 各記事から抽出したトンマナ上の特徴を**箇条書きで5〜8項目**に要約（語り口、見出しの傾向、断定の避け方、JSXタグの使い方、絵文字頻度、内部リンクの書き方など）

## 注意

- 記事本文そのものは長くなるので**貼らない**
- あくまで「次の記事生成でどういうトンマナに揃えるか」が一目でわかるサマリを出す
- 何か追加で読み込ませたい記事があるか、最後に一言だけユーザーに聞いて終了
